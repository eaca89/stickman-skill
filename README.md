# مهارت استیک‌من برای Claude (stickman skill)

یه مهارت (Skill) برای Claude که فیلم داستانیِ استیک‌من رو کامل با کد می‌سازه: آدمک‌ها رو می‌کشه، دوربین رو حرکت می‌ده، صدای افکت می‌ذاره و آخرش یه فایل MP4 تحویل می‌ده.

ساختهٔ **michxlai**، با مجوز آزاد MIT (فایل `LICENSE`). این ریپو فقط یه نسخه از همون مهارته تا دانلودش راحت باشه.

## نصب در Claude Code

1. روی دکمهٔ سبز **Code** بزن و **Download ZIP** رو انتخاب کن.
2. یه پوشهٔ خالی برای پروژه‌ات بساز و توی Claude Code بازش کن.
3. فایل ZIP رو به Claude بده و بنویس: «این مهارت رو برام نصب کن».

اگه می‌خوای خودت نصبش کنی: ZIP رو باز کن، اسم پوشه رو به `stickman` تغییر بده و بذارش اینجا:

```
<پوشهٔ پروژه>/.claude/skills/stickman/SKILL.md
```

## استفاده

توی Claude Code بنویس `/stickman` و بعدش داستانت رو توی یه پاراگراف. بار اول، مهارت ابزارهای لازم رو خودش روی کامپیوترت نصب می‌کنه.

---

**English.** A Claude skill that turns a story into a stickman film rendered entirely from code, with sound effects, delivered as an MP4.
Made by michxlai, MIT licensed (see `LICENSE`). This repository is a copy for easy download.
Install: download the ZIP, rename the folder to `stickman`, and place it at `.claude/skills/stickman/` in your project (or give the ZIP to Claude Code and ask it to install the skill). Use it with `/stickman` followed by your story.
